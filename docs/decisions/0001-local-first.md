# ADR-001: всё локально, без облака

**Статус:** принято, 2026-10

## Контекст

База знаний строительной компании: ГОСТы, регламенты, внутренние инструкции. Готовые SaaS-RAG (Notion AI,云端 векторные базы) требуют загрузки документов наружу — корпоративная база не должна покидать периметр.

## Решение

Весь стек работает на локальной машине:

- эмбеддинги и LLM — LM Studio (`localhost:1234`);
- индекс и поиск — mdrack (SQLite, файл на диске);
- агент и MCP-сервы — localhost.

## Последствия

- (+) приватность: ни один файл не уходит в сеть;
- (+) нулевая стоимость API при локальном железе;
- (−) качество LLM ограничено локальной моделью;
- (−) индексация зависит от производительности машины.
